# Genetic toolkit (3.0)

Choose neurons by **split-GAL4 driver line** instead of by cell type: Lab > **Genetic toolkit**, or `line:SS00727` anywhere a neuron
spec is accepted (brain surgery through the toolkit, the laser's target, thermogenetics, recordings, protocols, `Fly.neurons`).

The screen shows **line -> cell types -> neuron count**, the source's own **off-target** note, and buttons to silence or stimulate the
line's types, aim the laser at it, or express TrpA1 / shibire-ts in it ([thermogenetics.md](thermogenetics.md)).

## Where the mapping comes from

| what | tag | source |
|---|---|---|
| which cell types a line labels, and its expression quality | LITERATURE | Meissner et al. 2025, *A split-GAL4 driver line resource for Drosophila neuron types*, eLife 13:RP98405, [doi:10.7554/eLife.98405](https://doi.org/10.7554/eLife.98405), Figure 1-source data 1. **CC BY 4.0**, redistributed here with attribution |
| how many neurons carry a type | CONNECTOME | the brain pack (MaleCNS v1.0) |
| a name counts only if it is spelled exactly like a MaleCNS type | GAME RULE | `lab/genetics.py`: no prefixes, no synonyms, no fuzzy matching |

`kickthefly/data/driver_lines.yaml` holds 2,667 adult lines that name at least one cell type (the table lists 3,060 adult lines; the
rest name none). It is generated by `tools/build_driver_lines.py` from the published table, records the table's SHA-256, and is the only
way the file is meant to change. **No line name was written by hand**; one that I first remembered wrongly (SS00731 is DNa01 in the
table, not the giant fiber) is exactly why.

The data file lives in `kickthefly/data/`, not the repo's git-ignored `data/`, so it ships in the AppImage and exe.

## What it can and cannot tell you

- On the MaleCNS v1.0 pack 1,338 of the 2,667 lines have at least one cell type that matches a MaleCNS type; 962 of the table's 2,044
  cell-type names match. The table uses the light-microscopy literature's names (hemibrain, FlyWire, MANC style), which often differ
  from the MaleCNS ones. A line with no matching name selects **no neurons** and says so; it is not guessed at.
- **Off-target expression** is shown only as far as the paper says: quality 1 (one cell type, occasional weak expression elsewhere), 2
  (two cell types; if the table lists one, the second is off-target), 3 (three or more), 4 (weak or variable), 5 (not stabilized). Any
  other value is shown as written with "nothing is claimed". Expression strength, timing and what a line labels in a living fly
  beyond the score are not known here.
- **No GAL4 (non-split) lines.** No redistributable mapping of those to cell types was found, so none is offered. Add one only from a
  citable source, through `tools/build_driver_lines.py`.

## Python and protocols

```python
fly.line("SS00727")            # {'cell_types': ['DNp01'], 'matched': {'DNp01': 2}, 'neurons': 2, 'off_target': 'some', ...}
fly.neurons("line:SS00727")    # the rows
fly.silence("line:SS00727")
```

Example protocol: `protocols/genetics_line_silencing.yaml` (silence SS00727's neurons, looming stimulus, giant fiber recorded).
